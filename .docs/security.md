# Security and Maintenance

The auditable security state of the application for its whole life: its version, the security status of each component, vulnerabilities and advisories, accepted exceptions, and verifications. Components and versions live in [stack.md](stack.md), functional defects in [bugs.md](bugs.md), and pending security work in [backlog.md](backlog.md). Replace each `TODO`.

- Stable identifiers (`VULN-0001`, `RISK-0001`) and `YYYY-MM-DD` dates; keep resolved and retired rows.
- Take versions and statuses from verifiable sources and link the evidence; no secrets, personal data, or exploitable detail.
