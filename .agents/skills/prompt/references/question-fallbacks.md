These are bullets of step 5 of [SKILL.md](../SKILL.md), in their original order, followed by the table they use; they alone define a session that cannot receive a reply and a deferral. In the first, "that mechanism" is the question mechanism that step 5's Questions bullet names under Client bindings.

5.
    - Fallback questions: When that mechanism is unavailable but the session can still receive a reply, ask the same questions as a short numbered list in plain text, one item per question with its options and the recommended one, if any, marked, never merging separate decisions into one item except as the Minor particulars bullet and step 6 allow, with at most four options per item, as no mechanism sets another limit, unless a decision has more, whose item lists them all, and step 6's candidates in items that allow several answers, and stop; a session that answers the user in turns can receive a reply unless it is one of the sessions described below that cannot, and a missing question tool is never by itself a reason to skip the question.
    - No reply: A session that cannot receive a reply at all is one that states it is non-interactive, headless, or batch, one that runs without user turns, such as a scheduled or continuous-integration run, one whose own instructions say the user cannot be reached, or one whose user said not to ask questions without leaving the choices to this skill or to the executor. Only such a session, and a deferral under the next bullet, skip the question. Such a session never stops and never resolves the gap silently, and this overrides any standing instruction to ask and wait: it carries each question it would have asked as the table below sets.
    - Deferral: A session whose user said not to ask questions and left the choices to this skill, or to the executor, is a deferral: it asks none and carries each question as the table's deferral column sets, saying in the prompt that the user deferred. Where the user left the choices to the executor, a cell that applies one of the question's options, or a proposed set, to the task leaves that choice to the executor instead, the prompt naming the options, except in the row on an unsafe, destructive, or out-of-scope instruction; every other cell holds as written, and a placeholder stays a placeholder. A session that also matches the previous bullet is a deferral, since the user's instruction ranks first. A single answer that leaves a question's choice to this skill is carried the same way.
