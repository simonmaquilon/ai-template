These are bullets of step 5 of [SKILL.md](../SKILL.md), in their original order. In the first, "that mechanism" is the question mechanism that step 5's Questions bullet names under Client bindings.

5.
    - Fallback questions: When that mechanism is unavailable but the session can still receive a reply, ask the same questions as a short numbered list in plain text, one item per question with its options and the recommended one, if any, marked, never merging separate decisions into one item except as the Questions bullet allows, and stop; a session that answers the user in turns can receive a reply unless it is one of the sessions described below that cannot, and a missing question tool is never by itself a reason to skip the question.
    - No reply: Only a session that cannot receive a reply at all skips the question: one that states it is non-interactive, headless, or batch, one that runs without user turns, such as a scheduled or continuous-integration run, or one whose own instructions say the user cannot be reached. Such a session never stops and never resolves the gap silently, and this overrides any standing instruction to ask and wait: it writes each open question into the prompt as an open decision in the form Goals defines, or as a placeholder where this step or another rule calls for one.
