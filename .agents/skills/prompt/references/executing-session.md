# Executing session

The executing session is the one that will run the improved prompt. Unless the draft or the user says it is this session, assume it may run on another machine, under another account, or for another person, and write the prompt so it holds there. Facts about the target project are stated against a revision the executor can fetch, such as a commit hash or a remote branch, never against this session's working tree or local paths. State measured in this session's working tree, such as its current branch, uncommitted work, or running processes, and conditions of this session's environment, such as a blocked network route or a busy port, are labeled as observed here and are never presented as the executor's; the prompt requires the executor to measure its own before editing. A baseline measured on a clean copy of a revision carries that revision. A decision the prompt leaves for the executor to obtain names who takes it, by name or by role, when the draft or the user names someone, because the executor's user may be someone else, and otherwise goes to the executor's user, as Goals sets, and requires the answer to be cited where the work records it; a decision recorded as someone's without that citation is reported as unconfirmed.
