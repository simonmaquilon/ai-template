# Relevance of named artifacts

The last sentence of step 8 of [SKILL.md](../SKILL.md), moved here verbatim; the corrections label it uses is defined in [output-labels.md](output-labels.md).

Existence is not relevance: when the draft names artifacts as ones the change affects, such as suites, files, or documents, confirm that each one bears on the authorized change, while a side task the draft asks for explicitly is governed by Goals instead; ask the user about the ones that do not, or in a session that cannot receive a reply carry each as an open decision recommending to leave it out, report each under the corrections label, and where the executor must find others of the same kind, name the condition that selects them, so the executor does not open a list to find that most of it does not apply.
